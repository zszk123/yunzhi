# 开发计划 —— 知识库 + LangGraph Agent 系统

> **版本**：v1.0 ｜ **日期**：2026-09-20
> **配套文档**：[技术选型文档.md](./技术选型文档.md) ｜ [schema.sql](./schema.sql) ｜ Pixso 设计稿（8 页：登录 → Agent 创建 → 知识库 ×4 → Agent 对话/工作流）
> **节奏假设**：在职业余开发，每周 10–12 小时；总周期 **约 18 周（弹性 ±30%）**

---

## 1. 目标与范围

**一句话目标**：跑通"文档上传 → 解析分块 → 混合检索 → Agent 对话 / 工作流"全链路，交付设计稿定义的 8 页功能；每个迭代产出可演示成果，每个里程碑可写进简历。

**In Scope**：设计稿 8 页对应功能；RBAC 权限（3 角色）；单机 Docker Compose 部署；检索评测（Recall@k / MRR）。

**Out of Scope**（明确不做，防止范围蔓延）：多租户、高可用集群、移动端、实时协作、模型训练/微调、亿级向量、计费系统。

## 5. 节奏与弹性（时间不够时怎么砍）

**每周节奏建议**：工作日晚 3 × 2h（写代码）+ 周末 1 × 4h（整块攻坚）+ 0.5h（写周记，沉淀素材）。

**降级顺序**（按顺序砍，**砍范围不砍里程碑**）：

1. MinerU 解析 → 只保留 PyMuPDF（扫描件提示"暂不支持"）；
2. React Flow 拖拽画布 → 表单式编排（节点列表 + 下拉选择上游）；
3. 评测自建标注集 → 只测 Recall@k 单指标、50 条标注；
4. SSE 流式 → 同步返回 + loading 态。

**顺延规则**：单任务超期 3 天 → 触发降级；里程碑 M1/M2 超 1 周 → 复盘并压缩后续范围，不顺延日期。
